# 💫 About Me:
I’m Steven, a full‑stack engineer who cares a lot about building clear, reliable, and maintainable software. I work heavily with C# and .NET on the backend, and build web interfaces with React, Next.js, and TypeScript, plus Python and SQL when they make sense. I’ve also built desktop software that talks to PLCs and industrial machinery, and I automate anything that slows me down. Outside of work, I hang out with my dog, play guitar and piano, and still enjoy exploring ideas and building things just for the fun of it.
